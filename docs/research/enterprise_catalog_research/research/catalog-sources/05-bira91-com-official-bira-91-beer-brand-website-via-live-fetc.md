# Catalog Extraction Source: bira91.com (official Bira 91 beer brand website, via live fetch attempt + Wayback Machine archives)

- Source URL: https://bira91.com/
- SKUs extracted: 12
- Access notes: LIVE SITE STATUS (verified directly, High confidence on this specific fact): As of 2026-08-05, https://bira91.com/ does NOT serve the Bira 91 beer content. A direct HTTPS fetch returns a TLS certificate mismatch (cert is issued to *.ksmart.live, not bira91.com), and when fetched anyway over HTTP the server returns a stock 'Apache2 Ubuntu Default Page' — i.e., the domain currently points to a misconfigured/parked server, not the brand's real site. I verified this with both the WebFetch tool (which refused due to cert mismatch) and raw curl (which bypassed the cert check and got the Apache default page, HTTP 200, Content-Length 10671, Last-Modified Nov 2024, ETag matching the default Ubuntu Apache page). robots.txt returned empty/no content.

Because the live site is non-functional, all real product data had to be reconstructed from the Internet Archive Wayback Machine (web.archive.org), which is an independent third party's archived copies of the real bira91.com — not a live/current fetch. I confirmed via the Wayback CDX API that:
- The site was healthy and serving a proper Bira91 product site as recently as 17 Oct 2025 (HTTP 200), but by 8/10/18 Nov 2025 www.bira91.com started returning 503 errors, and the last successful full-page snapshot (3 Aug 2025 / then Oct 2025) showed the page had been reduced to just an "Age Gating" splash screen (title: "Bira | Age Gattting" [sic]) with no product content rendered in static HTML (content is likely JS-driven and wasn't captured).
- Detailed per-product pages with actual specs (ABV, ingredients, package sizes) only exist in archive snapshots from 2018 (a simpler 5-SKU site: White, Strong, Blonde, Light, IPA) and in 2023-2024 snapshots of a later redesign that added many more SKUs (Rise, Gold, Blonde Summer Lager, Boom/Boom Classic, Malabar Stout, IPA brewed with Pomelo, Superfresh White Citrus/Mango/Berry) but for which the archived HTML only preserved a lineup/nav grid (names + short taglines) and not the numeric ABV/calorie detail blocks — those appear to be injected by JavaScript that the Wayback Machine's static crawler did not capture.

CONFIDENCE AND METHOD NOTES:
- High confidence: the live-site status (broken/cert-mismatched/serving default Apache page) — directly observed today.
- Medium confidence: the 2018-era 5-SKU lineup (White 4.7% ABV / Strong 7% / Blonde 4.7% / Light 4% / IPA 7%), package sizes, and Light's calorie claim — directly read from archived HTML of the dedicated per-product pages, but the source itself is 6-8 years old and the 2024 snapshot shows the lineup and even some ABV/positioning had changed (e.g., 'Strong' and original 'IPA' don't appear by those exact names in the 2024 nav; Light's calorie count differs, 90 vs 80 calories, between the two eras' pages, an internal inconsistency I flagged rather than resolved).
- Low confidence: the newer 2023-2024 SKUs (Rise, Gold, Blonde Summer Lager, Boom, Malabar Stout, IPA brewed with Pomelo, Superfresh White Citrus/Mango/Berry) — I only recovered product names and one-line taglines from a lineup grid; no ABV, calories, or package size could be found for these in any page I could load, and I explicitly avoided guessing values for them (per the no-fabrication rule).
- Karnataka availability: NOT mentioned anywhere on bira91.com in any version I could access (2018 per-product pages, 2024 lineup pages, or the current broken site). I found no state-availability, "find near you", or store-locator content referencing Karnataka on the brand's own domain. This should be reported as "not found / not confirmed on-site" rather than assumed true or false.
- Barcode/GTIN, Karnataka MRP, and calorie data for any SKU beyond Light were not present on any bira91.com page I could retrieve, so those fields are omitted rather than guessed, per instructions.
- I could not access an authenticated or JS-rendered version of the current site (no browser-automation tool was available in this session besides basic fetch/curl), so it's possible the live site (when functioning normally, e.g. on a different day) contains additional or updated product/Karnataka-availability information not reflected in the static archived captures I used.
