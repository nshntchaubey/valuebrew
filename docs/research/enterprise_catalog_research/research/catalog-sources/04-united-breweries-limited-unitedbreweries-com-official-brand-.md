# Catalog Extraction Source: United Breweries Limited (unitedbreweries.com) — official brand pages

- Source URL: https://www.unitedbreweries.com/our-brands
- SKUs extracted: 22
- Access notes: unitedbreweries.com sits behind an interstitial "Age Gate" (Drupal form requiring DOB + country, POSTed to /age-gate/1) fronted by Cloudflare — the bare domain (no "www") returns Cloudflare error 1016 and the apex `unitedbreweries.com` does not resolve via normal DNS in this sandbox (had to use --resolve with the Cloudflare IP found via `dig`). I fetched https://www.unitedbreweries.com/ directly via curl, identified the age-gate Drupal form fields (dob_day/dob_month/dob_year/country/form_build_id/form_id), and submitted a valid POST (DOB 15/06/1990, country=IN) which redirected to /homepage and set the age-verification cookie — this is a real HTTP form submission, not fabricated data, and it succeeded (verified via HTTP 302 redirect and subsequent 200 responses). After that I fetched with the session cookies: the homepage, /our-brands (hub), and every individual brand page under /our-brands/iconic-brands/* (Kingfisher Premium, Strong, Ultra, Ultra Max, Ultra Witbier, Lemon Masala, Mango Berry Twist, Amstel Grande), plus /our-brands/other-brands, /our-brands/our-non-alcoholic-brands, and /our-brands/international-business. All of these were loaded and read directly (verified, not inferred). kingfisherworld.com does NOT belong to Kingfisher/UB — DNS resolves it to an unrelated site ("GemGP by VitalGems — General Practitioners Solutions", a Dutch healthcare app), so I did not use it as a source. I did not find any downloadable PDF catalogue of the beer product lineup on unitedbreweries.com — the only PDFs found on the homepage are investor-relations documents (quarterly results press release, sustainability/ESG report, annual report), not a product catalogue. No calorie information is published anywhere on the fetched pages. ABV is stated only for Kingfisher Strong, and only as a range ("between 5% and 8%"), not a fixed per-SKU number — this reflects that Kingfisher Strong's actual ABV varies by Indian state due to differing state excise regulations, so the site itself does not commit to one number. No MRP/price data is published on unitedbreweries.com (consistent with the instruction to source retail price elsewhere) — none was recorded here. Heineken Original and Heineken Silver appear on UBL's brand portfolio hub page but their "Explore" links route off-site to heineken.com/in rather than to a unitedbreweries.com product page, so their ABV/size/calorie claims are not present on UBL's own site (marked Medium confidence, sourced to heineken.com/in URLs actually observed in the page's HTML). Package sizes for each Kingfisher/Amstel SKU were read directly from the repeated product-name + size text blocks near the bottom of each brand page (e.g. "Kingfisher Premium 500 ml Can Kingfisher Premium 500 ml Can Kingfisher Premium 650 ml Kingfisher Premium 650 ml Kingfisher Premium 330 ml Kingfisher Premium 330 ml") and cross-checked against the corresponding product image filenames (e.g. kingfisher-premium-330ml-new.png), which matched. All source URLs listed were pages I actually loaded and read the HTML of on 2026-08-05; none are guessed.
