# Catalog Extraction Source: Open Food Facts (world.openfoodfacts.org)

- Source URL: https://world.openfoodfacts.org/api/v2/search?categories_tags=beers&countries_tags=india
- SKUs extracted: 11
- Access notes: Accessed Open Food Facts purely via its public JSON APIs (v2 /api/v2/search, /api/v2/product/{barcode}.json, and the legacy /cgi/search.pl) using curl with a custom User-Agent — no JS rendering, login, or location was required; the API returns raw JSON directly. Primary query used was https://world.openfoodfacts.org/api/v2/search?categories_tags=beers&countries_tags=india&page_size=100, which returned 20 total results (count=20). I then fetched each individual product's full record via /api/v2/product/{code}.json to verify fields before including it. I also ran targeted brand searches (brands_tags= and free-text search_terms=) for Kingfisher, Tuborg, Budweiser, Bira, Bira91, Carlsberg, Simba, White Owl, Godfather, Knock Out, Royal Challenge, and Haywards 5000. IMPORTANT CAVEAT: the OpenFoodFacts server returned HTTP 503 'Page temporarily unavailable' (rate-limiting) on a large fraction of requests despite waiting 5-20s between calls; I retried until I got HTTP 200 for the queries listed above, but several brand searches (Carlsberg, Bira91 as its own tag, Simba, White Owl, Godfather, Knock Out, Royal Challenge Beer) ultimately returned zero results even after successful 200 responses — meaning either these brands genuinely have no entries in OFF, or my searches didn't match how they're tagged there. I cannot rule out that additional Indian beer SKUs exist in OFF under different brand-tag spellings that I did not find given the rate limiting. From the categories_tags=beers+countries_tags=india result set, several entries were miscategorized/non-beer (a Cloud9 energy drink, a Cadbury chocolate bar, a Mapro mojito syrup, several French/Belgian abbey beers and a Cambodian 'Anchor White' beer that only spuriously carry an 'en:india' country tag) — I excluded those from the final list as not genuinely Indian beer SKUs. Every remaining entry I did include has data-quality problems typical of crowdsourced OFF data (missing brand fields, placeholder/garbled product names like 'P', 'beer', 'Boom', 'the originl') — I flagged each such issue explicitly in its last_verified_note rather than guessing the 'real' intended name. No ABV, calorie, or nutrition-per-serving data was found populated for any actual beer product across this whole search — those fields are omitted (not fabricated) for every SKU. No karnataka_mrp, manufacturer_url, or price data was found on Open Food Facts (it is not a retail/pricing database), so those fields are omitted throughout.
