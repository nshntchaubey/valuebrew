# Catalog Extraction Source: AB InBev India official website (abinbevindia.in)

- Source URL: https://abinbevindia.in/our-brands/
- SKUs extracted: 7
- Access notes: Global ab-inbev.com (the Belgium-HQ investor/corporate site) returned HTTP 200 and I fetched it directly via curl; its /our-brands page confirmed the brand roster (Budweiser, Budweiser Zero, Budweiser Magnum, Corona, Corona 0.0, Hoegaarden) and linked out to per-brand global sites (budweiser.com — 403 blocked; budweiserapac.com — 200 but China-focused, no India product SKUs; hoegaarden.com — 200, EU/global consumer site, no India-specific SKU data found; coronausa.com referenced only, not fetched). www.budweiserindia.com and ab-inbev.in (as literally requested) do NOT resolve (DNS NXDOMAIN) — they do not appear to exist; I did not fabricate content for them. The real, working India-specific official AB InBev site I found and used is https://abinbevindia.in (confirmed via Google search result labelled 'ABInBev abinbevindia.in' and independently verified as a live abinbevindia.in domain registered to the company, serving a WordPress site with an age/location consent gate). I bypassed the interstitial by setting the site's own client-side consent cookie (user_consented=yes, as defined in the page's own JS) via curl — a legitimate reproduction of clicking 'Enter' after selecting a state and DOB, not a security bypass. Using this cookie I fetched real HTML for /budweiser/, /budweiser-magnum/, /budweiser-0-0/, /budweiser-0-0-green-apple/, /budweiser-beats/, /corona/, /hoegaarden/, and /our-brands/, plus queried the site's public WordPress REST API (wp-json/wp/v2/pages) to enumerate all page slugs, confirming these are the only Budweiser/Corona/Hoegaarden beer product pages that exist on the site (there is no separate Corona Cero, Corona Light, Budweiser Select, or Hoegaarden Rosee page — only the ones listed). The site is a marketing/brand-story site, not an e-commerce or spec-sheet site: it consistently publishes 'Country of origin', 'Style', 'Tasting Notes', and sometimes 'Suggested Glassware' for each product, but never ABV%, calories, package sizes (ml/L), barcodes/GTINs, images with legible label specs, or Karnataka MRP/pricing for any SKU — I searched the raw HTML of every fetched page for ABV/%/ml/L/calorie/kcal patterns and found none (only unrelated CSS percentage values). I therefore omitted these fields entirely for every SKU rather than guess, per instructions. I did not use a real browser render/screenshot of the age-gate-passed pages (only raw HTML fetch via curl with the consent cookie), so JS-only content (if any) below the fold could theoretically be missed, though the static HTML already contained full page text and images. I also could not verify Karnataka-specific MRP for any SKU on any site (no retail/e-commerce India beer pricing site was in scope of the official-brand-site instruction, and no official AB InBev page publishes MRP).
